# MotiTasking

MotiTasking is a project that integrates gamification elements into a task management system to improve user motivation and productivity. Designed specifically for university students, it leverages modern gamification strategies to address common issues such as procrastination and lack of engagement. The system is built using the Cursor development platform, which enables rapid prototyping with real-time code suggestions.

Features
1. Points: Earn points for completing tasks and achieving milestones.
2. Badges: Unlock badges for consistency and meeting objectives.
3. Leaderboards: Track and compare task completion across users. (Non-functional)
4. Progress Bars: Visualize task completion and stay motivated.
5. Challenges: Set specific goals and track your progress to earn rewards.
6. Streaks: Maintain regular task completion streaks to boost motivation.
